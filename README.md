# 🧞‍♂️🕌 Flappy Carpet

**Flappy Carpet** is a Unity game similar to *Flappy Bird* with an **Aladdin-inspired theme** where the player controls a flying magic carpet through obstacles.

This project demonstrates game development fundamentals using **Unity**, including physics, player controls, collision handling, scoring mechanics, and visual design.

---

## 🎮 Gameplay Features

- Magic carpet player character
- Tap-based movement mechanics
- Collision detection with obstacles
- Score tracking based on progress
- Restart functionality after game over
- Aladdin-inspired visuals and atmosphere

---

## 🛠️ Technologies Used

- 🎮 **Game Engine:** Unity
- 💻 **Programming Language:** C#
- 🎨 **Assets:** Custom and Unity assets
- 🧠 **Concepts:** Physics, collision detection, game loops

---

## 🧠 What This Project Demonstrates

- Unity game development fundamentals
- Player movement and physics control
- Collision handling and game state management
- Scoring systems
- Game design inspired by classic arcade mechanics
- Creative theme adaptation
